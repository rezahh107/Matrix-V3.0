# راهنمای عیب‌یابی ساخت ماتریس

## خطای «Pool data missing canonical join-key columns»

این خطا زمانی رخ می‌دهد که استخر پشتیبان‌ها قبل از ورود به Core فاقد ستون‌های کاننیکال
سیاستی باشد. ستون‌های مورد انتظار همان ۶ کلید الحاقی هستند: `کدرشته`، `جنسیت`،
`دانش آموز فارغ`، `مرکز گلستان صدرا`، `مالی حکمت بنیاد`، `کد مدرسه` (همگی `int`).

### چرا این ستون‌ها در Excel من وجود ندارند؟
فایل‌های Inspactor/School معمولاً این نام‌ها را ندارند. Infra ستون‌های خام را به کمک
Crosswalk گروه، مرجع مرکز/مدرسه و نگاشت مالی به این کلیدهای کاننیکال تبدیل می‌کند.
اگر خطا را دیدید، یعنی مشتق‌گیری کامل نشده یا ورودی/مرجع ناقص بوده است.

### چک‌لیست برای اپراتور
1. مطمئن شوید فایل Inspactor و SchoolReport مطابق قالب جاری هستند و در آرگومان‌های CLI/UI
   درست انتخاب شده‌اند.
2. Crosswalk گروه و مرجع مدارس در SQLite به‌روز باشد (sync از WordPress/Policy).
3. QA خروجی استخر (`pool_join_key_derivation_issues`) را بررسی کنید؛ اگر reason code هایی مثل
   `MISSING_GROUP_CODE`, `UNKNOWN_CENTER`, `FINANCE_UNKNOWN`, `SCHOOL_NOT_FOUND` دیدید، مقدار
   خام را اصلاح یا مرجع را تکمیل کنید.
4. پس از اصلاح، import استخر را دوباره اجرا کنید و سپس ساخت ماتریس را تکرار کنید.
